# Contributing / Вклад в проект

Christmas Lights is a Windows WPF app. Before submitting a change:

- Build on Windows with the .NET 10 SDK and run all C# regression suites.
- Keep Audio Wave 3.0, continuous multi-monitor routing, LightCast and the Heart bulb geometry unchanged unless the change includes explicit tests and is approved.
- Provide reproduction steps for bugs, especially fullscreen behavior, Windows DPI, music/video routing and CL Studio.
- Do not commit generated EXE/installer artifacts, personal settings, credentials or private screenshots.
- For vulnerabilities, use GitHub's private security reporting where available; never publish exploit details.

**Licensing:** Before accepting external contributions or publishing the full source under an open-source license, the owner should choose and add explicit license terms.
