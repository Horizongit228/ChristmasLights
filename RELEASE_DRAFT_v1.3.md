# 🎄 Christmas Lights v1.3 — Aurora & Audio Wave 3.0

**Новый уровень праздничного света для Windows!** ✨

Christmas Lights превращает верхний край рабочего стола в красивую живую гирлянду. Теперь с музыкальными волнами, мягким цветным свечением, собственным редактором и поддержкой нескольких экранов.

## ✨ Что нового после v1.0

- 🎵 **Audio Wave 3.0** — световые волны реагируют на ритм музыки; для видео и полноэкранных приложений автоматически выбирается классическая реакция.
- 🌟 **LightCast** — мягкие цветные ореолы вокруг лампочек.
- 🎨 **CL Studio** — рисуй собственную гирлянду по одной лампочке, используй градиенты, узоры, зеркальное рисование и сохраняй дизайны.
- 🌈 **Индивидуальные цвета** — яркость и насыщенность каждого оттенка по отдельности.
- 🖥️ **Infinity Garland** — продолжение гирлянды через несколько мониторов, с общим звуковым потоком и сквозными волнами.
- 💜 **Aurora UI** — обновлённый тёмный интерфейс, цветовой редактор и новые удобные инструменты.
- 💡 **Обновлённые анимации** — дыхание, мерцание, волны, искры и бегущие цвета.
- 💾 **Сохранность настроек** — резервные копии настроек и дизайнов.

## ⬇️ Скачать / Download

Скачай **`ChristmasLights.exe`** или архив **portable ZIP** в разделе **Assets** ниже, а затем запусти программу на Windows.

**Поддержка:** Windows 10 (19041+) / Windows 11, x64. В portable EXE уже включён необходимый .NET runtime.

> Перед обновлением закрой предыдущую Christmas Lights через системный трей. Пользовательские дизайны рекомендуется сохранить дополнительно.

## 🛡️ Безопасность

Системный звук обрабатывается локально и используется для световых эффектов. Приложение может быть без цифровой подписи. Проверяй SHA-256 из приложенного `SHA256.txt` и загружай файлы только из официальных Releases.

Нашёл ошибку? Напиши в [GitHub Issues](https://github.com/Horizongit228/ChristmasLights/issues).

## 🌍 English

**Christmas Lights v1.3** brings cozy fairy lights to your Windows desktop with **Audio Wave 3.0**, ambient **LightCast**, a fully customizable **CL Studio**, per-color brightness and saturation, multi-monitor **Infinity Garland**, and polished **Aurora UI**.

Choose your bulb shapes and palettes, save your custom designs, and let the lights dance to music.

**Download the portable EXE or ZIP from Assets.** Windows 10 (19041+) or Windows 11 x64. No separate .NET installation is needed for the portable build.

Audio processing is local. You can report issues via [GitHub Issues](https://github.com/Horizongit228/ChristmasLights/issues).
