# Security policy

The latest public version is currently **v1.0.0**. The v1.3 release candidate is in testing and **has not been published as stable**.

Report sensitive vulnerabilities using the repository's private security advisory / vulnerability reporting option, if enabled. Otherwise request a private reporting channel from the maintainer; do not post exploit details in public Issues.

Verify SHA-256 checksums from official GitHub Releases. Checksums do not replace code signing, malware scanning or safe download practices.
