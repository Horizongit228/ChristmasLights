# Как опубликовать Christmas Lights v1.3 на GitHub

Сейчас **v1.0.0** — единственный проверенный публичный релиз. Ветка `release/v1.3-preparation` предназначена для подготовки кандидата.

1. Скачай исходники `ChristmasLights-v1.3.0-rc1-ReleasePreparation-SOURCE.zip` из нашей рабочей переписки.
2. На Windows запусти `packaging/Prepare-GitHub-Branch.ps1` в распакованном проекте. Он **только** клонирует ветку и копирует исходники в отдельную папку; ничего не отправляет на GitHub.
3. Посмотри `git status` и проверь код. Если хочешь публиковать исходники на условиях open-source, сначала выбери и добавь файл `LICENSE`.
4. Закоммить и отправь исходники в `release/v1.3-preparation` (НЕ в `main`). После этого Windows CI будет доступен для реальной сборки.
5. Запусти `Build-Check.cmd`, затем `Build-EXE.cmd`, а для установщика `Build-Installer.cmd` (нужен Inno Setup).
6. Выполни [чек-лист](RELEASE_CHECKLIST.md); проверь SHA-256 итогового EXE, фото и работу на Windows 10/11, при одном и нескольких мониторах.
7. Только после этого создай GitHub **Prerelease** `v1.3.0-rc.1`. Стабильный `v1.3.0` — отдельный шаг после проверки.

**Альтернатива:** можно оставить GitHub в формате binary-only, как в v1.0, и вручную прикрепить проверенные файлы к prerelease. Тогда CI не сможет собирать приложение без исходников в репозитории.

Нельзя удалять старый выпуск `v1.0.0` или выдавать неподтверждённую сборку за стабильную.
