# Privacy / Конфиденциальность

Christmas Lights v1.3 candidate processes audio locally through Windows audio APIs (WASAPI) to animate lights. Wallpaper color extraction also runs locally. The inspected source has no sign-in or analytics service. The application stores preferences and CL Studio designs in `%APPDATA%\\ChristmasLights\\` as JSON and keeps `.bak` backups for recovery. It is not designed to upload audio or wallpapers.

**For bug reports:** do not publish `settings.json`, `studio.json`, personal screenshots or system details without checking them for private information. GitHub has its own privacy policy for issues and downloads.

Программа локально анализирует воспроизводимый звук и цвета обоев; настройки и дизайны хранятся на компьютере. Не публикуй конфиденциальные данные в GitHub Issues.
